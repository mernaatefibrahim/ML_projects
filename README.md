# 🤖 Machine Learning Projects

A collection of Machine Learning projects built using Python, covering **data preprocessing, exploratory data analysis, regression, classification, computer vision, and ML deployment**.

## 📂 Projects

### 🏠 1. House Price Prediction

A Machine Learning regression project that predicts house prices based on different features such as:

- Location
- Area / Square Feet
- Number of Bedrooms (BHK)
- Number of Bathrooms

**Technologies:**
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook

**Main concepts:**
- Data Cleaning
- Exploratory Data Analysis
- Feature Engineering
- One-Hot Encoding
- Train/Test Split
- Linear Regression
- Model Evaluation
- Prediction

📁 Project folder: `project/`

### 👤 2. Celebrity Image Classifier

A Computer Vision and Machine Learning project that identifies a celebrity from an uploaded image.

The classifier currently recognizes:

- Mohamed Salah
- Farida Osman
- Mostafa Shobeir
- Sara Samir
- Maria Sharapova

**Technologies:**
- Python
- OpenCV
- NumPy
- PyWavelets
- Scikit-learn
- Flask
- HTML
- CSS
- JavaScript

**Main concepts:**
- Image preprocessing
- Face Detection
- Haar Cascade
- Wavelet Transform
- Feature Extraction
- Machine Learning Classification
- Model Prediction
- Flask API
- Web Interface

📁 Project folder: `CelebrityFaceRecognition/`
